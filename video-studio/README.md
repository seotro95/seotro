# Video Studio VN

Ứng dụng web tiếng Việt chạy cục bộ để tải, biên tập phụ đề, tạo giọng đọc và xuất video.

Trên Windows: đọc [HUONG_DAN.md](HUONG_DAN.md), chạy `cai_dat.bat`, đặt FFmpeg/FFprobe cạnh launcher, sau đó chạy `khoi_dong.bat`.

Mã nguồn được xây dựng riêng theo mô tả chức năng trong tài liệu đã cung cấp. Gói này không bao gồm VideoToolsPro.exe, key, cookie hay các dịch vụ nội bộ của phần mềm mẫu.

Kiểm thử: `python -m unittest discover -s tests -v`.
